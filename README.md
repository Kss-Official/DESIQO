## 🌟 Overview

DESICO (DESIQO) is an enterprise-grade AI content preparation and governance platform. It orchestrates a 7-agent pipeline designed to automate multi-platform social media campaign creation, compliance validation, and scheduled dispatch with a deterministic zero-bypass approval gate.

## 🚀 Quick Start (Frontend)

```bash
cd frontend
npm install
npm run dev
```

Visit [http://localhost:3000](http://localhost:3000) to view the live interface.

## 🛡️ Key Features

- **7-Agent Pipeline**: Master Orchestrator, Research & Event Agent, Content Agent, Design Agent, Quality & Compliance Agent, Publishing Agent, and Analytics Agent.
- **Deterministic Governance**: 100% human-in-the-loop admin gate before any post touches social platforms.
- **Platform Adapters**: Official API integration for LinkedIn, Meta/Facebook, Instagram, Pinterest, X (Twitter), and Google Gemini.
- **High-End Visual Aesthetic**: Warm Cream Beige (`#E8D2B5`) design system, Deep Burgundy (`#590907`) typography, 3D interactive particle systems, and Lenis smooth scrolling.
